# Bus Timer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Siri on the iPhone says when the next MBTA Route 220 bus leaves Bridge St @ Blackstone Rd for Quincy Center. The answer comes from a small service on the Synology NAS.

**Architecture:** One standard-library Python file (`app.py`) serves `GET /bus`. It gets predictions from the MBTA v3 API and returns one plain-text sentence. It runs in Docker through Synology Container Manager. An iOS Shortcut gets the URL and speaks the text.

**Tech Stack:** Python 3.12 (container) / 3.14 (Mac, for tests), standard library only, `unittest`, Docker + Compose, Synology Container Manager 24.0.2, iOS Shortcuts.

**Spec:** `bus-timer/docs/superpowers/specs/2026-10-10-bus-timer-design.md`

## Global Constraints

- Use the Python standard library only. No `pip install`, no `requirements.txt`.
- Defaults: `STOP_ID=3614`, `ROUTE_ID=220`, `DIRECTION_ID=1`, `DESTINATION=Quincy Center`, `PORT=8220`. `MBTA_API_KEY` is optional.
- The MBTA request timeout is 10 seconds. Send the `x-api-key` header only when a key is set.
- The response is `text/plain; charset=utf-8`. Only `/bus` gives a 200; every other path gives a 404.
- Clock times use `America/New_York`, 12-hour format, no AM/PM. Minutes are rounded down. Under 1 minute is "arriving now".
- The error sentence is exactly: `I couldn't reach the MBTA right now.` The full traceback goes to stderr.
- The files on the NAS live in `/volume1/docker/bus-timer`. NAS IP is `192.168.50.251`.
- Claude has no root on the NAS. Only the user can start containers there (Container Manager web UI).
- **No git commits.** `/Users/mark/python/.gitignore` ignores `bus-timer/`, and the user will sort that out later. Skip every commit step.
- All paths below are relative to `/Users/mark/python/bus-timer/`. Run all commands from that folder.

## Review Focus

1. **Cancelled or skipped trips:** the MBTA sends predictions where both `departure_time` and `arrival_time` are `null`. Skip them; don't crash. → Task 1 test `test_skips_predictions_without_times`.
2. **UTC timestamps (`...Z`):** convert to Boston time before speaking the clock time. → Task 1 test `test_clock_time_is_converted_to_boston`.
3. **Afternoon times:** 13:05 must be spoken as "1:05", not "13:05". → Task 1 test `test_clock_time_is_12_hour`.
4. **Shortcut URL with a query string or trailing junk:** `/bus?x=1` still works, and `/` gives a 404, not a crash. → Task 2 tests `test_bus_path_with_query_string` and `test_other_paths_are_404`.
5. **MBTA down, rate limited (HTTP 429), or bad JSON:** Siri must still say a sentence, not an error page. → Task 2 test `test_mbta_failure_gives_spoken_error`.

```python
"""Say when the next MBTA bus leaves my stop, as one sentence for Siri."""

from datetime import datetime
from zoneinfo import ZoneInfo

BOSTON = ZoneInfo("America/New_York")


def upcoming_departures(payload, now):
    """Return the predicted departure times that are not in the past, sorted."""
    departures = []
    for item in payload.get("data", []):
        attributes = item.get("attributes", {})
        stamp = attributes.get("departure_time") or attributes.get("arrival_time")
        if stamp is None:
            continue
        when = datetime.fromisoformat(stamp)
        if when >= now:
            departures.append(when)
    return sorted(departures)


def describe_wait(when, now):
    minutes = int((when - now).total_seconds() // 60)
    if minutes < 1:
        return "arriving now"
    if minutes == 1:
        return "in 1 minute"
    return f"in {minutes} minutes"


def clock_time(when):
    local = when.astimezone(BOSTON)
    return f"{local.hour % 12 or 12}:{local.minute:02d}"


def format_message(departures, now, route, destination):
    """Make the sentence Siri speaks from the first two departures."""
    if not departures:
        return f"No {route} buses are predicted right now."
    first = departures[0]
    message = (
        f"The next {route} to {destination} is "
        f"{describe_wait(first, now)}, at {clock_time(first)}."
    )
    if len(departures) == 1:
        return message + " No other buses are predicted yet."
    return message + f" The one after is {describe_wait(departures[1], now)}."
```

```python
"""Say when the next MBTA bus leaves my stop, as one sentence for Siri."""

import json
import os
import traceback
import urllib.parse
import urllib.request
from datetime import datetime
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from zoneinfo import ZoneInfo

BOSTON = ZoneInfo("America/New_York")
MBTA_URL = "https://api-v3.mbta.com/predictions"

STOP_ID = os.environ.get("STOP_ID", "3614")
ROUTE_ID = os.environ.get("ROUTE_ID", "220")
DIRECTION_ID = os.environ.get("DIRECTION_ID", "1")
DESTINATION = os.environ.get("DESTINATION", "Quincy Center")
PORT = int(os.environ.get("PORT", "8220"))
API_KEY = os.environ.get("MBTA_API_KEY", "")
```

Add this to the end of `app.py`:

```python
def fetch_predictions():
    """Get the live predictions for our stop, route and direction from the MBTA."""
    query = urllib.parse.urlencode({
        "filter[stop]": STOP_ID,
        "filter[route]": ROUTE_ID,
        "filter[direction_id]": DIRECTION_ID,
        "sort": "departure_time",
    })
    request = urllib.request.Request(f"{MBTA_URL}?{query}")
    if API_KEY:
        request.add_header("x-api-key", API_KEY)
    with urllib.request.urlopen(request, timeout=10) as response:
        return json.load(response)


def bus_message():
    """Return the sentence for Siri. A failed MBTA call is logged, not raised."""
    try:
        payload = fetch_predictions()
    except Exception:
        traceback.print_exc()
        return "I couldn't reach the MBTA right now."
    now = datetime.now(BOSTON)
    return format_message(upcoming_departures(payload, now), now, ROUTE_ID, DESTINATION)


class BusHandler(BaseHTTPRequestHandler):
    def do_GET(self):
        if urllib.parse.urlsplit(self.path).path != "/bus":
            self.send_error(404)
            return
        body = bus_message().encode("utf-8")
        self.send_response(200)
        self.send_header("Content-Type", "text/plain; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)


def main():
    server = ThreadingHTTPServer(("", PORT), BusHandler)
    print(f"Listening on port {PORT}", flush=True)
    server.serve_forever()


if __name__ == "__main__":
    main()
```
